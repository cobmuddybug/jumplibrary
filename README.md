# Jumplibrary

A personal collection of 250+ playable Jumpchain documents created for solo chains, niche settings, and experimental builds.

## About This Archive

This repository serves as an open-access mirror for jumpdocs generated using a heavily iterated, custom LLM writing workflow (Claude) designed around standard Jumpchain conventions, Choice Point (CP) economies, origin discounts, and drawback scaling. 

This archive is maintained independently for players looking for playable jumps covering settings that don't yet have traditional community docs, or for solo jumpers who want a large, ready-to-use library.

## Usage

* **Play & Fork:** Feel free to download, adapt, house-rule, or build upon any document in this collection for your own chains.
